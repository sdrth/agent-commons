# Agent Commons

**Make your AI agents work together.**

One shared Google Drive. Multiple personal AI agents. No new app, plugin, download, server or subscription.

You may already use ChatGPT, Claude, Grok, Instinct, Dots, Town or other assistants. Each has its own context, tasks, automations and limits. You end up repeating yourself, paying for duplicated work and losing track of what is happening.

Agent Commons is an open set of working instructions that lets your agents coordinate through a workspace you own. Your agents may change. Your workspace shouldn't.

## Get started

Send this message to the first agent you want to join:

> Read https://github.com/sdrth/agent-commons and its AGENT-COMMONS.md instructions. I want you to join Agent Commons using my Google Drive. First inspect what you can access, identify existing trackers, work, preferences and automations, then propose a setup and ask me any necessary questions. Do not modify anything until I approve. Preserve and backfill my existing work.

Once the first agent has set up or identified the shared folder and sheet, give their links to the other agents along with the same message. Each agent discovers its own work and asks before joining. Onboard agents one at a time to avoid duplicate workspaces.

You need a Google Drive account and a way for at least one agent (or you) to read and write Drive files and Sheets. Use whatever access your agents already support. Agent Commons itself requires no installation. If an agent can only read, or cannot access Drive, it can participate through copy-ready updates for you or another authorised agent to apply. It must disclose that limitation. If an agent cannot open GitHub, paste the instructions into the chat instead.

## What changes

- Before substantial work, agents check existing work, claim ownership and reuse previous outputs.
- Active work, goals, routines, agent capabilities, usage and handoffs are visible in one Google Sheet.
- Each agent keeps its own worklog, useful files, instructions and portable automation backups in Drive.
- Agents suggest assignments based on access, privacy, expertise, reliability and available capacity.
- One short weekly review identifies unfinished work, redundant routines, failures and decisions you need to make.

The system works alongside existing trackers, folders and optional tools such as Todoist. It does not replace working systems by default. It cannot force an agent to run in the background, access another provider, or synchronise automatically.

## Your workspace

```text
Your Google Drive / Agent Commons/
  Instructions.md
  About Me & Goals.md
  Preferences & Decisions.md
  Approval Rules.md
  Agent Commons (Google Sheet)
  Shared Knowledge/
  Weekly Reviews/
  Agents/
    Your agent's folder/
      Profile.md, Context.md, Worklog.md, Usage.md
      Automations/, Workflows/, Work/, One-offs/
  Archive/
```

The five sheet tabs are **Work, Routines, Agents, Usage, Inbox**. Existing equivalent files and tabs are welcome. The GitHub repository holds public instructions only; your real work, personal context and account details stay in your private, approved Drive workspace.

## Principles

User-owned. Provider-independent. Portable. Cooperative. Minimal.

No master agent, central execution engine, custom database, mandatory API or continuous monitoring. Agent Commons is a convention, not software. It only works when participating agents actually follow it and have the access they claim to have. A Sheet is not a guaranteed exclusive lock. The user resolves conflicts and authorises sensitive or consequential actions.

## Inspiration

Agent Commons builds on ideas from [Project Loop](https://github.com/sdrth/project-loop): unfinished outcomes, stable IDs, evidence-based tracking, incremental discovery and closure. Agent Commons extends these principles to cooperation across independent agents.

## Contribute

Share improvements to the instructions, field-tested workflows and examples using fictional or redacted data. Never post real user records, private Drive links, secrets or conversation history to this repository or its issues.
